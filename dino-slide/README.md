# Dino Runner 16:9

Jogo independente inspirado no Chrome Dino, preparado para apresentação widescreen.

## Abrir
Depois que o GitHub Pages publicar a atualização, abra:
https://xmyguel-x.github.io/dino-slide/

## Controles
- Espaço ou seta para cima: pular / iniciar / reiniciar
- Seta para baixo ou S: abaixar
- Clique ou toque: pular / iniciar / reiniciar
- Botão Tela Cheia: ampliar a área do jogo

O jogo usa o sprite sheet já existente em `/dino/sprite-1x.png`. Não altera o jogo principal nem o mod THE LAST RUN.
